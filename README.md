# WP Text to Speech

Multilingual WordPress text-to-speech plugin using the browser SpeechSynthesis API.

## Languages

Hindi (`hi-IN`), Bengali (`bn-IN`), Gujarati (`gu-IN`), Kannada (`kn-IN`), Malayalam (`ml-IN`), Marathi (`mr-IN`), Punjabi (`pa-IN`), Tamil (`ta-IN`), Telugu (`te-IN`), Urdu (`ur-PK`), English, Spanish, French, German, Italian, Portuguese, Japanese, and Chinese.

## Installation

Upload this repository to `wp-content/plugins/wp-text-to-speech`, activate it, then open **Text to Speech** in WordPress administration. Select a language, speed, pitch, position, and post types.

Language playback depends on voices installed in the visitor's browser or operating system. No external API or audio service is required.
